# 請求書取り込み（Googleドライブ ＋ スプレッドシート）

取引先の請求書を **Googleドライブのフォルダに入れるだけ** で、Claude が内容を読み取り、スプレッドシート「支払い一覧」に登録します。
支払ったら「支払済」にするだけで、支払日と **「お振込みいたしました」の連絡メール文** が自動で入ります。

```
請求書PDF・画像を「請求書/受付」フォルダに入れる
   ↓「📥 請求書を取り込む」ボタンを押す
Claude が読み取り → 「支払い一覧」に1行追加 → ファイルは「処理済/2026/09/」へ移動・改名
   ↓
担当者が内容を確認 → 確認者名を入力 → 銀行で振込
   ↓
ステータスを「支払済」に → 支払日と連絡メール文が自動で入る → コピーして取引先へ送る
```

- 銀行振込・メール送信は自動では行いません（メール文はコピーして使います）
- 読み取り結果は誤ることがあるため、怪しいものは「未確認」＋「要確認」にチェックが付きます
- サーバーやPCの常時起動は不要です（スプレッドシートに付けるプログラム＝Google Apps Script で、ボタンを押したときに動きます）

## 支払い一覧の見方

| 列 | 内容 |
| --- | --- |
| ステータス | 未確認 / 未払い / 支払済 / 保留 / 対象外 |
| 要確認 | 読み取りに不安があるものにチェック。理由は「備考」列 |
| 確認者 | 内容を確認した人の名前。**空欄のままだと「支払済」にできません**（二重チェックのため） |
| 支払期限・請求日・取引先・請求金額・税額・内容・請求書番号 | 請求書から読み取った内容 |
| 銀行名〜口座名義 | 振込先 |
| 請求書ファイル | クリックでPDFを開けます |
| 支払日・連絡メール文 | 「支払済」にすると自動で入ります |
| 備考 | 要確認の理由、AIの確信度、元のファイル名 |

**支払期限アラート**（未払い・未確認・保留の行）

- 🟥 赤: 期限切れ
- 🟧 オレンジ: 期限まで3日以内
- 🟨 黄: 期限まで7日以内
- 支払済の行は文字がグレーになります

**「未確認」になるとき**: AIの確信度が低い / 金額や支払期限が読み取れない / 振込先が複数ある / 再発行・訂正・差替の記載がある / 外貨建て / 読み取りエラー

**請求書ではない書類**（見積書・納品書・領収書など）は登録せず「対象外」フォルダへ移動します。
**読み取れなかったファイル**（パスワード付きPDF、未対応の形式など）は「未確認」の行を残して「読取エラー」フォルダへ移動します。

## 初回セットアップ（15分程度）

### 1. AnthropicのAPIキーを発行する

1. <https://console.anthropic.com/> にログイン（アカウントが無ければ作成）
2. 「Billing」で支払い方法を登録し、クレジットを購入
3. 「API Keys」→「Create Key」でキーを作成し、表示された `sk-ant-...` をコピー（あとで使います）

> Claude のチャット（claude.ai）の契約とは別に、APIの利用料（従量課金）がかかります。

### 2. スプレッドシートを作ってプログラムを貼り付ける

1. Googleスプレッドシートを新規作成（名前は例えば「支払い管理」）
2. メニュー「拡張機能」→「Apps Script」を開く
3. 最初からある `コード.gs` の中身を全部消し、このフォルダの [`apps-script/Code.gs`](apps-script/Code.gs) の中身を丸ごと貼り付けて保存（💾）
4. 左の「⚙️ プロジェクトの設定」で **タイムゾーンを「(GMT+09:00) 日本標準時」** にする
5. スプレッドシートのタブに戻り、ページを再読み込み（F5）
6. メニューに「請求書」が表示されます

### 3. 初期設定

1. メニュー「請求書」→「⚙️ 初期設定」
2. 初回は「承認が必要です」と出るので、自分のGoogleアカウントを選んで許可します
   （「このアプリはGoogleで確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」。自分で作ったプログラムなので問題ありません）
3. フォルダのURLを聞かれます
   - 空欄のままOK → マイドライブに「請求書」フォルダが作られます
   - 既存のフォルダを使う場合は、そのフォルダのURLを貼り付け
4. 「受付」フォルダのURLが表示されたら完了です。「支払い一覧」「処理ログ」シートも作られます

作られるフォルダ:

```
請求書/
  受付/        ← ここに請求書を入れる
  処理済/2026/09/  ← 読み取り後に自動で移動（請求日の年月で分類）
  読取エラー/
  対象外/
```

### 4. APIキーを設定

メニュー「請求書」→「🔑 APIキーを設定」で、手順1のキーを貼り付けます。

### 5. 試してみる

1. 請求書PDFを1つ「受付」フォルダに入れる
2. メニュー「請求書」→「📥 請求書を取り込む」
3. 「支払い一覧」に1行増えればOK

### （任意）シート上に取り込みボタンを置く

1. 「挿入」→「図形描画」でボタンの形の図形を作り「保存して閉じる」
2. 図形を右クリック →「︙」→「スクリプトを割り当て」→ `menuImport` と入力

## 日々の使い方

1. 請求書（PDF・JPEG・PNG）を「受付」フォルダに入れる（スマホのGoogleドライブアプリからでもOK。何枚かまとめて入れてもOK）
2. メニュー「請求書」→「📥 請求書を取り込む」（またはシート上のボタン）を押す
3. 「支払い一覧」で内容を確認。**「未確認」の行は請求書と見比べて修正**し、ステータスを「未払い」に
4. 確認した人が「確認者」に名前を入力
5. 振込したらステータスを「支払済」に → 支払日と連絡メール文が入る
6. 連絡メール文のセルを選んで、メニュー「✉️ 選択行の連絡メール文を表示」→「コピー」→ メールに貼り付けて送信

> 支払日を後から直した場合も、「✉️ 選択行の連絡メール文を表示」で最新の内容に作り直せます。

### 連絡メール文の例

```
件名：お振込み完了のご連絡（請求書番号 INV-1234）

株式会社サンプル
ご担当者様

お世話になっております。

本日（2026年9月29日）、請求書記載の金額をお振込みいたしました。
請求書番号：INV-1234／お振込金額：110,000円
ご確認のほどよろしくお願いいたします。

引き続きよろしくお願いいたします。

ワールドダイブ株式会社
```

## 設定の変更

`Code.gs` の先頭の `CONFIG` を書き換えて保存します。

| 項目 | 内容 | 初期値 |
| --- | --- | --- |
| `COMPANY_NAME` | メール文の署名 | `ワールドダイブ株式会社` |
| `MODEL` | 使うClaudeのモデル | `claude-opus-5-5` |
| `EFFORT` | 読み取りの丁寧さ（`low` / `medium` / `high`）。上げると精度↑・時間と費用↑ | `low` |
| `CONFIDENCE_THRESHOLD` | これ未満のAI確信度は「未確認」 | `0.8` |
| `REQUIRE_CHECKER` | `false` にすると確認者なしでも「支払済」にできる | `true` |

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| メニュー「請求書」が出ない | スプレッドシートを再読み込み。それでも出なければ Apps Script で保存できているか確認 |
| 「APIキーが正しくない」 | 「🔑 APIキーを設定」でキーを貼り直す。Anthropic側で残高（クレジット）があるか確認 |
| 「Claude APIが混雑しています」 | ファイルは受付に残っています。少し待ってからもう一度「📥 請求書を取り込む」を押してください（3回失敗すると「読取エラー」へ移動） |
| 取り込まれない | 「処理ログ」シートを確認。ファイルが「受付」フォルダの直下にあるか確認 |
| 読み取り内容が間違っている | シートを直接修正してください（再取り込みは不要） |
| もう一度読み取らせたい | 該当行を削除し、ファイルを「受付」フォルダに戻す |

## 開発者向け

- プログラム本体: [`apps-script/Code.gs`](apps-script/Code.gs)（1ファイル）
- マニフェスト: [`apps-script/appsscript.json`](apps-script/appsscript.json)（`clasp` で管理する場合に使用。手で貼り付ける場合は不要）
- テスト: Google のサービスを偽物に差し替えて Node で実行します

```bash
cd invoice-automation
npm test
```
